# 系統更新：統一加班補貼及供餐邏輯

## 1. 系統設定介面更新 (Settings UI)
- **統一補貼設定**：在「總務設定」畫面，移除了原本專為外籍員工設計的假日加班選項，改為**全體適用的統一加班補貼**。
  - 新增：平日加班 4hr+、假日加班 8hr、10hr、12hr+ 的獨立津貼金額設定。
- **儲存與套用**：所有的設定值（包含標籤與金額）皆已串接後端 `/api/settings`，確保能動態儲存並套用於結算。

## 2. 自動供餐邏輯更新 (Auto-Ordering)
- **平日自動供餐**：系統在產生每日餐單時，會檢查加班時數 (`ot_hours >= 2`)，若達標則自動將 `hasDinner`（晚餐）打勾。
- **假日停供餐**：根據與人資系統的串接 (`IS_REST_OVERTIME === 1`)，若是假日加班，系統會**自動關閉午餐與晚餐** (`hasLunch = false`, `hasDinner = false`)，需由警衛手動處理訂餐。

## 3. 財務結算模組更新 (Finance & Export)
- **免費便當折抵 (免費供餐)**：
  - 因應「平日加班滿2小時，公司免費供餐」規則，現在結算時會先統計出因平日加班而訂的晚餐（`free_dinners`），並從員工總用餐數中**自動扣除不計費**。
  - 計算公式：`應扣伙食費 = (總便當數 - 免費便當數) × 單價`
- **統一加班津貼計算**：
  - 獨立統計出「平日 4hr+」、「假日 8hr」、「假日 10hr+」、「假日 12hr+」的天數。
  - 無論本國籍或外國籍，皆會依照設定的津貼金額將這些天數折算成應發津貼（外勞的返鄉底數折算與原住宿減免規則保留）。
- **結算畫面與 Excel 匯出**：
  - 結算表格已加入「平日加班4hr+(天)」與「假日加班12hr+(天)」的新欄位，並同步更新至匯出的 Excel 檔案中。
