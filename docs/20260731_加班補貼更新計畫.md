# 平日/假日加班補貼新制 實作計畫 (更新版)

根據您的確認，新制一體適用於本國與外籍員工，並且假日時自動關閉訂餐。

## 💡 關於外勞「住食 2400」的想法與系統設計建議

您提到外勞簽約已含住食 2400，沒住會補貼。我的想法與系統建議如下：

1. **平日午餐與正常供餐**：住校外勞因為有扣 2400，平常的午餐本來就「包在裡面」，不需額外扣款。無住宿外勞則因為公司退還（或沒扣）這 2400，所以若他們平常吃午餐，財務結算時應該要從薪水「扣除便當費（應扣伙食費）」。
2. **加班的「免費」供餐**：這次新規定提到「平日加班滿 2 小時，公司統一供餐」，這通常被視為公司的**加班福利**。也就是說，這頓「加班晚餐」是**免費的**。
   - **系統處理方式**：在每月底的財務結算 Excel 中，因為平日加班 (>=2hr) 而產生的晚餐，**不應該計入「應扣伙食費」中**。系統在結算時，會自動將這部分的便當數排除，不讓員工因為加班吃便當而多扣錢（無論他有沒有住宿）。
3. **平日加班滿 4 小時的 75 元補貼**：這個補貼是無論本外勞、有無住宿，只要達到條件，結算時就會額外發放 75 元。

## 📅 如何判斷假日？

我剛才查閱了 HR 系統的 API 資料結構，發現 HR 系統的打卡與加班紀錄中，內建了一個欄位叫作 `IS_REST_OVERTIME`（是否為休息日加班）。
- 我們可以直接讀取這個值！如果 HR 系統判斷這筆加班是 `IS_REST_OVERTIME = 1`，系統就會自動認定今天是假日。
- 這樣的好處是：不管是排休、國定假日、或是週末，只要 HR 系統認定是休息日，點餐系統就會自動同步，**不需要我們自己寫程式判斷星期六日或手動輸入國定假日**。

## 🛠️ 預計修改內容總結

### 1. 總務設定頁面
- **本國/外籍 加減項名目統一**：既然新制一體適用，我會在設定頁加入統一的補貼金額設定：
  - 平日加班 (>=4hr) 補貼：$75
  - 假日加班 (>=8hr) 補貼：$75
  - 假日加班 (>=10hr) 補貼：$150
  - 假日加班 (>=12hr) 補貼：$225

### 2. 每日訂餐邏輯 (`server.js`)
- **平日**：如果 `IS_REST_OVERTIME == 0`，且 `ot_hours >= 2` ➡️ `hasDinner = true` (自動訂晚餐)。
- **假日**：如果 `IS_REST_OVERTIME == 1` ➡️ 完全關閉自動訂餐 (無論是否加班，`hasDinner = false`，`hasLunch = false`)，交由警衛手動處理。

### 3. 財務結算邏輯
- 結算時掃描每位員工整個月的加班紀錄，計算出符合 4hr, 8hr, 10hr, 12hr 的天數，並乘上對應的補貼金額，列為「加項（應發津貼）」。
- 確保因為「平日加班」而產生的晚餐，**不列入**需要扣款的便當總數中。
